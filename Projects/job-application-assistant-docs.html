Overview

The Job Application Assistant is a full-stack web application that automates and streamlines the job application lifecycle. It scrapes job descriptions from LinkedIn and Naukri, extracts tech stacks, matches them against a user's uploaded resume, generates tailored resumes and cover letters, provides interview preparation materials, and offers a tracking dashboard for managing applications.

The system follows a modular architecture with a Python/FastAPI backend, a PostgreSQL database for persistence, and a single-page frontend. AI/LLM capabilities power text analysis (tech stack extraction, resume matching, interview Q&A generation), while dedicated libraries handle document parsing and generation.

Glossary

Portal — The Job Application Assistant web application providing all job application assistance features.
JD_Scraper — Component that fetches and extracts job description content from external URLs.
Tech_Stack_Extractor — Analyzes a JD and identifies required technologies, frameworks, tools, and skills.
Resume_Matcher — Compares a parsed JD against the user's base resume and calculates a match score.
Resume_Editor — Generates resume edit suggestions and produces a modified Word document.
Interview_Prep_Generator — Generates interview topics and categorized Q&A sets based on a JD.
Base_Resume — The user's existing resume uploaded to the Portal, used as baseline for comparison.
Match_Score — Percentage (0–100) representing resume-to-JD alignment.
Experience_Level — User's self-reported level (Fresher, Junior, Mid, Senior, Lead/Architect).
Difficulty_Category — Classification of interview questions: Easy, Medium, or Difficult.

Requirements

Requirement 1: Job Description Scraping

As a job seeker, I want to provide a job posting URL from LinkedIn or Naukri so that the portal can automatically extract the job description without manual copy-pasting.

Acceptance Criteria

  • WHEN a user provides a valid LinkedIn job posting URL, THE JD_Scraper SHALL extract the job title, company name, job description text, and listed requirements.
  • WHEN a user provides a valid Naukri job posting URL, THE JD_Scraper SHALL extract the job title, company name, job description text, and listed requirements.
  • IF the URL is not a recognized LinkedIn or Naukri URL, THEN return a descriptive error message indicating the URL is unsupported.
  • IF the fetch fails due to network error or access restriction, THEN return a descriptive error message indicating the failure reason.
  • WHEN successfully scraped, present the extracted JD to the user for confirmation before further analysis.

Requirement 2: Tech Stack Extraction

As a job seeker, I want to see the tech stack required for a job so that I can quickly understand the technical expectations.

Acceptance Criteria

  • Identify and list all programming languages, frameworks, libraries, tools, databases, and cloud platforms mentioned in the JD.
  • Categorize extracted technologies into "Required" and "Nice-to-Have" based on JD language.
  • If no technologies found, inform the user and suggest manual review.

Requirement 3: Resume Upload, Parsing, and Persistence

As a job seeker, I want to upload my resume once and have it saved for future use so that I do not need to re-upload it every time.

Acceptance Criteria

  • Accept Base_Resume uploads in PDF (.pdf) and Word (.docx) formats.
  • Parse the resume and extract structured sections: contact info, skills, work experience, education, certifications.
  • Persist the Base_Resume and parsed data for reuse across sessions.
  • Use stored Base_Resume for all subsequent analyses without re-upload.
  • Replace previously stored resume when a new one is uploaded.
  • Allow user to view stored resume details (file name, upload date, skills summary).
  • Return descriptive errors for unsupported file types or corrupted/unreadable files.

Requirement 4: Resume-to-JD Matching

As a job seeker, I want to see how well my resume matches a job description so that I can assess my fit for the role.

Acceptance Criteria

  • Compute a Match_Score as a percentage (0–100) representing alignment.
  • Provide breakdown: matched skills, missing skills, matched experience keywords, missing experience keywords.
  • Display score with summary categorization: "Strong Match", "Moderate Match", or "Weak Match".
  • Weight technical skills, experience, and education separately with individual sub-scores.

Requirement 5: Resume Edit Suggestions

As a job seeker, I want specific suggestions on how to improve my resume for a particular job.

Acceptance Criteria

  • Generate specific, actionable edit suggestions to improve alignment.
  • Categorize suggestions: "Skills to Add", "Experience Descriptions to Rephrase", "Keywords to Include", "Sections to Reorder".
  • Prioritize by estimated impact on Match_Score (high-impact first).
  • Preserve factual accuracy — only rephrase, reorder, and optimize keywords.

Requirement 6: Tailored Resume Generation in Word Document

As a job seeker, I want a new, tailored Word document resume for each job application.

Acceptance Criteria

  • Produce a new .docx with suggested changes applied to a copy of the Base_Resume.
  • Preserve original formatting, fonts, and layout structure.
  • Highlight or annotate modified sections for easy identification.
  • Provide a download link for the generated document.
  • Leave persisted Base_Resume unchanged — each generated resume is a separate document.
  • Convert PDF-uploaded resumes to Word format before applying edits.
  • Associate each tailored resume with the corresponding job description.

Requirement 7: Interview Preparation Topics

As a job seeker, I want to know what topics to prepare for the interview so I can study efficiently.

Acceptance Criteria

  • Generate interview preparation topics relevant to the job description.
  • Categorize into "Technical Topics", "Domain Knowledge Topics", and "Behavioral/Soft Skill Topics".
  • Rank topics by relevance with the most critical first.

Requirement 8: Interview Q&A Generation

As a job seeker, I want practice questions and answers tailored to the job and my experience level.

Acceptance Criteria

  • Generate questions and model answers for each topic.
  • Categorize each question: Easy, Medium, or Difficult.
  • Generate scenario-based questions with realistic workplace situations.
  • Tailor depth and complexity to the user's Experience_Level.
  • Minimum 5 questions per Difficulty_Category per major topic.
  • Include expected answer with key points highlighted for quick review.

Requirement 9: Job Application Tracking Dashboard

As a job seeker, I want a dashboard to track all jobs I've analyzed and applied to.

Acceptance Criteria

  • Maintain history of all analyzed JDs: title, company, date, Match_Score, tailored resume link.
  • Dashboard view: tabular or card-based layout.
  • Update application status: Not Applied, Applied, Interview Scheduled, Interview Completed, Offered, Rejected.
  • Add/edit free-text feedback notes per entry.
  • Delete job entries from the dashboard.
  • Auto-create dashboard entry with "Not Applied" status on new JD analysis.
  • Filter and sort by status, date, company name, or Match_Score.
  • Summary view: total analyzed, applied, interviews scheduled, offers received.

Requirement 10: Cover Letter Generation

As a job seeker, I want a tailored cover letter for each job without writing one from scratch.

Acceptance Criteria

  • Generate cover letter tailored to JD, incorporating skills and experience from Base_Resume.
  • Structure: opening paragraph, body paragraphs highlighting qualifications, closing paragraph.
  • Adjust tone and content depth based on Experience_Level.
  • Allow user to review and manually edit before downloading.
  • Provide download link in .docx format.
  • Associate with corresponding job entry in tracking dashboard.

Requirement 11: Skill Gap Analysis and Learning Resources

As a job seeker, I want to understand my skill gaps and get learning resource recommendations.

Acceptance Criteria

  • Identify all skills in JD that are absent from Base_Resume.
  • Categorize gaps: "Critical" (required) and "Recommended" (nice-to-have).
  • Suggest learning resources for each gap.
  • Display skill gap analysis alongside Match_Score breakdown.

Requirement 12: Application Deadline and Reminder Tracking

As a job seeker, I want to set deadlines and reminders so I don't miss application windows.

Acceptance Criteria

  • Set application deadline date per job entry.
  • Display days remaining indicator for entries with deadlines and "Not Applied" status.
  • Urgent visual indicator when deadline is within 2 days.
  • Edit or remove deadlines from any entry.
  • Sort by approaching deadlines.

Requirement 13: Job Description Comparison

As a job seeker, I want to compare multiple JDs side by side to prioritize applications.

Acceptance Criteria

  • Select two or more analyzed JDs for side-by-side comparison.
  • Structured comparison: title, company, required/preferred skills, experience, Match_Score.
  • Highlight differences and commonalities in required skills.
  • Indicate which role has the highest Match_Score.

Requirement 14: Export Interview Preparation as PDF

As a job seeker, I want to download interview prep as a PDF for offline study.

Acceptance Criteria

  • Export interview topics and Q&A as a PDF document.
  • Format with clear section headings, difficulty labels, and readable answers.
  • Include job title and company name for reference.
  • Provide download link for the generated PDF.

Requirement 15: JD Parsing and Pretty Printing

As a job seeker, I want a well-structured view of the scraped JD to quickly understand the role.

Acceptance Criteria

  • Parse raw content into structured fields: title, company, location, experience, description, required/preferred skills.
  • Display parsed JD in a clean, readable layout.
  • Round-trip property: parsing → formatting → parsing produces an equivalent object.

Service Components

1. JD Scraper Service

Fetch and extract structured job description data from LinkedIn and Naukri URLs.

class ScrapedJD(BaseModel): job_title: str company_name: str location: str | None experience_required: str | None description_body: str required_skills: list[str] preferred_skills: list[str] raw_html: str class JDScraperService: async def scrape(self, url: str) -> ScrapedJD: ... def _detect_platform(self, url: str) -> str: ... def parse_to_structured(self, raw_text: str) -> ScrapedJD: ... def format_pretty(self, jd: ScrapedJD) -> str: ...

2. Tech Stack Extractor

Analyze job descriptions and extract categorized technology requirements via LLM.

class TechStackItem(BaseModel): name: str category: str # "language", "framework", "database", "cloud", "tool" priority: str # "required" or "nice_to_have" class TechStackExtractorService: async def extract(self, jd_text: str) -> TechStackResult: ... async def identify_skill_gaps(self, tech_stack, resume_skills) -> SkillGapResult: ...

3. Resume Parser Service

Parse uploaded resumes (PDF/DOCX) into structured data using LLM section extraction.

class ParsedResume(BaseModel): contact: ContactInfo skills: list[str] experience: list[WorkExperience] education: list[Education] certifications: list[str] raw_text: str class ResumeParserService: def parse(self, file_path: str, file_type: str) -> ParsedResume: ...

4. Resume Matcher Service

Compute weighted match scores between resumes and job descriptions.

class MatchBreakdown(BaseModel): overall_score: float # 0-100 skills_score: float experience_score: float education_score: float matched_skills: list[str] missing_skills: list[str] category: str # "Strong Match", "Moderate Match", "Weak Match" class ResumeMatcherService: def compute_match(self, parsed_resume, scraped_jd) -> MatchBreakdown: ...

5. Resume Editor Service

Generate edit suggestions and produce tailored Word documents.

class EditSuggestion(BaseModel): category: str # "skills_to_add", "experience_rephrase", etc. description: str impact: str # "high", "medium", "low" original_text: str | None suggested_text: str | None class ResumeEditorService: async def generate_suggestions(self, match, resume, jd) -> list[EditSuggestion]: ... def generate_tailored_docx(self, base_path, suggestions) -> str: ...

6. Interview Prep Service

Generate interview topics and categorized Q&A sets tailored to experience level.

class InterviewPrepService: async def generate_topics(self, jd) -> list[InterviewTopic]: ... async def generate_qa(self, topics, jd, experience_level) -> list[InterviewQA]: ... # Min 5 questions per difficulty per major topic # Includes scenario-based questions

7. Cover Letter Service & 8. Export Service

class CoverLetterService: async def generate(self, resume, jd, experience_level) -> str: ... def export_docx(self, content, job_title, company) -> str: ... class ExportService: def export_interview_prep_pdf(self, topics, qa, job_title, company) -> str: ...
