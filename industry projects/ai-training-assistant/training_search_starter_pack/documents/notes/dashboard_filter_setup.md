# Dashboard Filter Setup Notes

Document type: SOP note  
Status: Sanitized starter material  
Primary users: Operations analysts and team coordinators

## When this note is used
Use this note when a team member needs to configure saved filters on the operations dashboard for queue monitoring, exception review, or daily work allocation.

## Standard filter setup
1. Open the operations dashboard.
2. Select the active queue from the left panel.
3. Use the filter drawer to choose date range, request status, owner, and exception type.
4. Save the filter with a name that includes team, queue, and purpose.
5. Share the filter only with the assigned workgroup unless supervisor visibility is required.

## Naming convention
Use the format:

`Team - Queue - Purpose - Month`

Example: `Ops Desk - Refund Exceptions - Pending Review - Jun`

## Required filter fields
- Queue type
- Current status
- Assigned owner
- Created date range
- Priority or escalation marker
- Exception category, where available

## Common issues
- Users sometimes save filters without a date range, causing old closed records to appear.
- Shared filters may show blank results if the user does not have access to the queue.
- Screenshot evidence should include the filter drawer and the result count where possible.

## Review note
If a filter is used for supervisor review, include the filter name and screenshot reference in the handover message.
