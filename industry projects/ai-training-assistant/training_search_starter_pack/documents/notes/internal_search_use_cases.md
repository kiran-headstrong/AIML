# Internal Search Use Cases for Training Content

This file lists typical operations questions that the content search assistant should support.

## Access request questions
- What information is required before routing a user access request?
- Which access role requires supervisor review?
- When should temporary access include an expiry note?

## Approval escalation questions
- When does an approval item move from L1 follow-up to supervisor review?
- What should be included in an escalation note?
- When should a request be marked as manual freeze?

## Refund exception questions
- Which refund requests require finance ops validation?
- What is the minimum information required for a refund exception?
- What should not be promised in a refund exception routing note?

## Dashboard screenshot questions
- Where is the filter drawer located?
- Which screenshot shows the saved filter naming area?
- What should be visible in a screenshot attached for supervisor review?

## Quality review questions
- What fields should be checked during monthly quality review?
- How many records are recommended for a small-team monthly review?
- When should a repeated error pattern be escalated?
